Use BrowserOS neo in session-owned tabs. Test the updated production-mode local build at http://localhost:3100. It uses isolated Docker Postgres at localhost:55432/gocart_e2e. Treat localhost:3000 and https://go-cart-iota-eight.vercel.app as shared/live environments: read-only checks there. The latest source changes have not been deployed. Do not use the existing deployment as evidence for the local patch.

First verify that 3100 renders after a hard reload. Record prolonged loading screens, hydration errors, failed scripts and requests. Do not force-hide loaders. Local Vercel telemetry script 404s are expected outside Vercel; distinguish those from application errors.

Use existing isolated customer, seller and admin test accounts. Do not reset passwords or change production roles. Missing credentials or fixtures mean BLOCKED. Database integration supplies a controlled authenticated identity; it does not verify browser authentication.

1. Store pagination: /store/gocart-demo-store has 25 products. Verify 24 cards on page 1 and one on page 2. Persistent search fixture: /store/portfolio-pagination-store?search=PortfolioPagination has 50 matches, with pages 24 / 24 / 2. Verify all 50 unique product URLs, no omissions, disabled boundary buttons, reload, Previous and browser back/forward. Test page=999 recovery and page=abc, 0 and -1. Check 375px controls and horizontal overflow. /store/portfolio-empty-store is a seeded active store with zero products; /store/portfolio-single-store has one. Neither should show pagination. Do not use an unseeded store URL as an empty-store fixture. Restore these fixtures with bun run db:e2e:portfolio-fixtures; the script is guarded to local gocart_e2e and is idempotent.
2. Filters: brand, rating, category, offer, color, size, price and search. Start on page 2; a filter/sort change resets to page 1 while retaining other filters. Prices survive reload. Verify both price directions across all three fixture pages using each product's discounted minimum price. The fixture has brand Portfolio Fixture, rating 4, Standard size, two colors and offer portfolio-regression-offer on half the products. Report each filter separately; checking price and sort alone does not establish all filters work. No duplicates or omissions. These 50 products persist until explicitly reset; they are separate from the temporary integration-check fixture.
3. Images: inspect home, store, browse, suggestions and product pages. Known dead legacy Unsplash URLs show placeholders; other failures recover without endless skeletons or broken icons. Switch variants while hovering: correct image, reset index, no accumulating timers. Wishlist network failure causes no unhandled rejection.
4. Financial dashboards: on isolated data and sandbox payment methods, record baselines, pay an order, partially refund, fully refund and process a chargeback if supported. Compare actual order-group totals and recorded commissions with admin/seller values. GMV includes Paid and PartiallyRefunded at full group total; Refunded and Chargeback are excluded. Monthly buckets use group creation dates in UTC. GMV is not profit. Verify visible-tab refresh within 60 seconds, focus refresh, seller ownership and active-store changes. Real-DB status-transition tests already passed; they do not prove provider/browser flows.
5. Security regression: verify customer/seller denial of admin operations, other users' order/address/payment/return details and other sellers' products/inventory. Test normal uploads and rejection of unsupported active file types and oversized files, including submissions bypassing the widget. Verify Cloudinary preset restrictions separately: URL validation does not establish uploaded byte safety. Test Jodit save/reload with legitimate formatting and non-destructive XSS markers on seller/customer/admin views; no marker may execute. Test quantity/numeric bounds, malformed inputs and privileged extra fields. Limited-coupon simultaneous checkout requires dedicated concurrency verification; a sequential success does not prove atomic quota enforcement. Restrict all mutations to isolated fixtures.
6. Phase 26: POST /api/queues/email, inventory, notification and payment returns 503, never a success acknowledgement for unprocessed messages. Queue migration is intentionally inactive.
